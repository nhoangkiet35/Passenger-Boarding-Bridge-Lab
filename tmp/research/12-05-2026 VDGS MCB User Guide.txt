Introduction 
About MCB
Manual Control Board (MCB) is a resistive touch sensitive device, which enables the
user to manually operate A-VDGS. The resistive touch screen allows the operator to
use the MCB with gloves on their hands.  
Operators can use MCB to take local control of the gate and dock aircrafts through
A-VDGS.  
During normal situations, the docking activation for A-VDGS is automated through a
central system.
  
The operator can use MCB in certain situations such as:
• Loss of connectivity between the A-VDGS and central system
• An unscheduled aircraft arrival for docking
• Manual overrides for correction  of any activation errors.
• Initiate emergency stop to abort the docking process in case of any apron 
emergency
• View error messages from the A-VDGS unit

Emergency Stop Button 
MCB is housed in an external enclosure. An emergency stop button is provided on
the right side of the enclosure. 
This button is directly connected to the Docking Controller (DC) in PDU.  
During any of the following emergency situations, the docking process can be
stopped using the emergency stop button. 
• Probability of hazard to the aircraft, humans or property.
• A wrong aircraft entering the gate.
• Probability of incursion of the airc raft with ground vehicles / objects
• The aircraft overshooting its expected stop position beyond configured safety 
limits
Pressing this button will terminate the docking process and the word STOP is
displayed in red on the PDU.
To end the emergency stop signal, turn the Emergency Stop button clockwise and
release the Emergency Stop key.
The system returns to its earlier state (prior to Emergency stop was pressed), if no
other error condition exists. 
Note:
If the system is in LOCAL mode and the earlier state was ACTIVE, then, the
operating state returns to FREE.

In this mode, central system is in control of A-VDGS and data cannot be fed through
MCB. Docking activation is done by A-VD GS in co-ordination with central system.
Data for System status, Gate and Aircraft are fetched from the DC.
Local
In certain situations such as connectivity  issues, downtime of central system, or
unplanned  aircraft arrival, the operator at the stand can take local control of A-VDGS
by using Local mode in MCB.
In this mode, the operator can perform docking procedures manually.
Update the system to the Remote mode  when the manual docking procedure is
complete.
Maintenance
The Maintenance mode is used while performi ng test activities or when the gate is
under maintenance. This option switches A-VDGS to maintenance mode indicating
that the stand is being used for non-docking activities.
