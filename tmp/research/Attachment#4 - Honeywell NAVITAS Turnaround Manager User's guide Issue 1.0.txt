Introduction 
About Turnaround Manager 
Efficient, safe, and hassle-free aircraft docking operations play a vital role in
managing large airports across the world. Honeywell NAVITASTM Turnaround
Manager (TMAN) provides tools that help th e operators and the controllers manage
the apron area efficiently while ensuring safe operations. 
TMAN has an event-driven architecture . It is an automated gate management
system that delivers higher gate efficiency and optimized throughput while ensuring
smooth operations (arrival and departure). Working in tandem with the Honeywell A-
VDGS PA3+ system , it displays a graphical overview of the airport and provides
comprehensive control of the complete docking system. 
In this chapter:
Sections See Page
Features 19
Types of Users 20

Features 
TMAN, along with the A-VDGS, provides real -time apron information for monitoring
purposes and allows the user to intervene when required. The live video streaming
feature allows the user to have a visual understanding of the actual events.
The following are the salient features of the TMAN application:
Docking operations
• Displays the scaled graphical map of the airport with an option to navigate to the
individual terminal view. 
• Displays the following information in the graphics area for easy recognition and
faster decision making:
• Color-coded representation of the stand/docking position status
• Color-coded representation of the Multiple Apron Ramp System (MARS)
• Symbolic representation of the Aircraft size  
• Displays comprehensive Stand information
(component status and queued flights) 
• Allows manual docking activations
• Displays real-time/live view of the apron area
• Enables Events and Alerts management  
(for the components in the turnaround system)
• Enables Flight plans management 
(allows users to manage flight plans and view turnaround information)
• Allows publishing of customized me ssage to the Pilot display units (PDU)
• Allows simultaneous tracking of multiple stands
Maintenance operations
• Allows the configuration and monitoring of components
(PDU, Stand, Aircraft, Control systems, and its connections)
• Allows software version management 
• Upload a new version
• Verify current version
• Install the latest version
• Provides application-level user management features for stand-alone
deployments.  Has the ability to integrate with airport-wide identity management
and SSO services.
