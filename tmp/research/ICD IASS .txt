2.Specification for IASS monitoring software for Long Thanh International Airport 
 
The ShinMaywa’s Smart Airport Management System(SSMS) is an Integrated software 
monitoring system that caters to the needs of any Airport in the world. It consists of 4 
major components; 
 
1. Data collection 
2. Web Portal Management 
3. Data exchange 
4. 3D Interactive display 
 
 
Data Collection 
The data collection component is designed to poll data from each of the PLC on the PBB. Data 
collected can be referenced to the list in Appendix I. Data collection from other sources is 
possible using standard Modbus protocol or by means of software API provided by the 
respective Vendors of the equipment. 
 
Web Portal Management 
The web portal provides data to day operational functions and reports as listed in Appendix II. 
 
Data Exchange 
The Data Exchange system is responsible for sending required data to other software systems 
by means of direct input of data into SQL servers or by means of API provided by the respective 
software vendors.

3.1 Flight integration 
GetFlightInfo 
The IASS system integrate with IB to retrieve flight information for PBB monitoring and to serve as the 
foundational data for reports. 
For each PBB gate, the IASS system will show the currently docked flight and the next scheduled arrival. 
Assuming that the typical interval between one flight docking at a gate and the next flight docking at the same 
gate is 4 hours, the IASS system might set an expectation to retrieve flight information for the next 5 hours.  
• This approach avoids obtaining information for flights scheduled much further in advance, which may 
be subject to reassignment to different gates or cancellation. 
• Though, if allocation changes or flight cancellations occur, the information returned by the same 
method should include a flight change indicator.
